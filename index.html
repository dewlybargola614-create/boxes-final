Game setup

Teams

Use 2–8 teams. Add or remove teams here before saving.

Upload question pictures

Upload screenshots or image files (PNG, JPG, WEBP). Each image becomes a question. The student board will draw questions randomly and will not show image filenames. Questions, teams and scores are saved on this device, so they come back if the page reloads. They are never uploaded anywhere. Use "Remove all questions" to clear them for a different class. Use images sized for a widescreen screen when possible.

Tip: upload images in the order you want them to appear. To replace an image, remove it and upload the new one. Question images are not edited by this game.

Design notes

Built for the classroom TV

  • Large touch targets
  • One question per screen
  • Persistent score panel
  • Teacher-controlled answer checking
  • Undo last score change
  • Used boxes stay unavailable
  • Fullscreen mode
  • No internet or account required
Before class: upload the question screenshots, set team names, and test one turn.
